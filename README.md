# 🐍 Mamba3-Yui — 多模态永续合约交易智能体

基于 **Mamba3 SSM** 架构 + **PPO 强化学习** 的虚拟货币永续合约交易智能体。

> 像专业交易员一样思考和交易 — 同时感知技术面、消息面、链上数据、微观结构和宏观经济五大维度。

## ✨ 核心特性

- **Mamba3 SSM 架构** — ICLR 2026 最新状态空间模型，线性复杂度 + 无限历史记忆
- **多时间框架分析** — 5m/1h/4h/1D 四层编码器 + 跨周期注意力融合
- **多模态感知** — K线 + 新闻情绪(FinBERT) + 链上数据 + 订单簿 + 宏观经济
- **分层决策** — 宏观判断→战术执行→仓位管理，模拟真人决策链路
- **市场状态自适应** — 自动识别趋势/震荡/高波动，调整交易策略
- **专业风控** — 动态止盈止损、追踪止损、仓位缩放、单笔亏损限制

## 🏗️ 架构

```
五大维度输入 → 独立编码器 → 跨模态门控融合 → 市场状态检测 → 分层 RL 决策 → 风控层 → 交易指令
```

## 📁 项目结构

```
├── configs/            # 配置文件
├── src/
│   ├── model/          # Mamba3 核心 + 编码器 + 融合 + Agent
│   ├── env/            # Gymnasium 交易环境
│   ├── data/           # 数据采集 + 特征工程
│   ├── training/       # 预训练 + PPO + 训练管理
│   └── backtest/       # 回测引擎 + 评估指标
├── scripts/            # 入口脚本
└── tests/              # 单元测试
```

## 🚀 快速开始

```bash
# 安装依赖
pip install -r requirements.txt

# 下载数据
python scripts/fetch_data.py

# 训练模型 (预训练 + RL)
python scripts/train.py --config configs/default.yaml

# 回测评估
python scripts/backtest.py --checkpoint best_model.pt
```

## 📊 训练流程

1. **阶段 1 — 监督预训练**：训练编码器学会"看盘"（方向/波动率/市场状态预测）
2. **阶段 2 — 强化学习**：PPO 算法训练分层 Agent 学会"做决策"（课程学习）
3. **阶段 3 — 微调优化**：消融实验 + 超参数搜索
